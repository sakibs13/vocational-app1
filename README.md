# ভোকেশনাল পাঠশালা (Vocational Learning & Physics App)

কারিগরি ও ভোকেশনাল কারিকুলামভুক্ত ৯ম, ১০ম, একাদশ ও দ্বাদশ শ্রেণির শিক্ষার্থীদের জন্য পদার্থবিজ্ঞান ও ট্রেডভিত্তিক সম্পূর্ণ ফ্রি উন্মুক্ত শিক্ষা মোবাইল অ্যাপ্লিকেশন।

---

## 📱 অ্যাপের বৈশিষ্ট্যসমূহ
1. **শ্রেণি নির্বাচন (Class 6 - 12):**
   - ৬ষ্ঠ থেকে ৮ম শ্রেণির জন্য বিজ্ঞান ও গণিত ফাউন্ডেশন।
   - ৯ম ও ১০ম (এসএসসি ভোকেশনাল) এবং একাদশ ও দ্বাদশ (এইচএসসি ভোকেশনাল / বিএমটি)।
2. **ভোকেশনাল বিশেষ ক্যাটাগরি (Class 9 - 12):**
   - **সাধারণ বিষয়সমূহ (Common Subjects):** পদার্থবিজ্ঞান, রসায়ন বিজ্ঞান, সাধারণ গণিত, বাংলা, ইংরেজি, ধর্ম ও নৈতিক শিক্ষা।
   - **৪টি প্রধান কারিগরি ট্রেড:**
     - ⚡ জেনারেল ইলেকট্রিক্যাল ওয়ার্কস (Electrical)
     - 💻 আইওটি বেসিকস ও কম্পিউটার (IoT Basics)
     - 🔧 মেশিন টুলস অপারেশন (Machine)
     - 🏗️ সিভিল কনস্ট্রাকশন (Civil)
3. **অধ্যায়ভিত্তিক লেকচার ভিডিও:**
   - বিজ্ঞাপন ও ডিস্ট্রাকশনমুক্ত ইউটিউব ভিডিও স্ট্রিমিং।
4. **পিডিএফ ও হ্যান্ডনোট:**
   - গুগল ড্রাইভে হোস্টকৃত ফ্রি লেকচার নোট ও সমাধান ইন-অ্যাপ রিড ও ডাউনলোডের সুবিধা।

## 🛠️ সরাসরি APK বিল্ড করার উপায় (GitHub Actions - সম্পূর্ণ ফ্রি)

আপনার পিসিতে যদি ভারী Android Studio বা Flutter ইনস্টল না থাকে, তবে গিটহাব ব্যবহার করে মাত্র ২ মিনিটে ক্লাউড থেকে সরাসরি APK ডাউনলোড করে নিতে পারেন:

1. এই ফোল্ডারের কোডগুলো একটি নতুন GitHub রিপোজিটরিতে আপলোড করুন।
2. `.github/workflows/build_apk.yml` ফাইলটি দেওয়া আছে।
3. GitHub-এর **Actions** ট্যাবে গিয়ে **Build Android APK** এ ক্লিক করে **Run workflow** বাটনে চাপ দিন।
4. ২-৩ মিনিটের মধ্যে স্বয়ংক্রিয়ভাবে `Vocational-Physics-App-Release` নামের রেডিমেড `.apk` ফাইল তৈরি হয়ে যাবে, যা আপনি সরাসরি ফোনে নামিয়ে চালাতে পারবেন।

## 💻 লোকাল মেশিনে রান ও বিল্ড করার নিয়ম (যদি Flutter থাকে)

```bash
# ডিপেনডেন্সি ইনস্টল করুন
flutter pub get

# ডিভাইসে রান করুন
flutter run

# প্রোডাকশন রিলিজ APK তৈরি করুন
flutter build apk --release
```
বিল্ড হওয়া APK ফাইলটি পাওয়া যাবে: `build/app/outputs/flutter-apk/app-release.apk`
